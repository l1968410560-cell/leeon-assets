# leeon 品牌卡（深空数据舱）

> 所有 leeon 内容的视觉基准。做图 / PPT / 视频前先读这张卡，**全平台统一**。

## 一、品牌定位

- 人设：数据党 leeon —— AI 领域的"冷静拆解者"，先技术后搞钱。
- 视觉关键词：深空、数据舱、克制、高级感、科技但不炫技。

## 二、色彩令牌（≤3 色原则）

| 令牌 | 色值 | 用途 |
|---|---|---|
| 近黑底 | `#05060B` | 主背景（不纯黑） |
| 暖白 | `#E8EAED` | 正文 / 次级文字 |
| 强调青 | `#22D3EE` | 数字、关键结论、进度条（唯一强调色） |
| 半透明边框 | 白 10-14% | 卡片描边 |
| 灰阶辅助 | `#3A3F4A` 等 | 分隔线 / 弱化元素 |

规则：
- 全片/全图不超过 3 色：近黑 + 灰白 + 1 个强调色。
- 强调色只用在数字、结论、进度条，其余灰阶。
- 禁止彩虹渐变、双高亮、emoji 配色。

## 三、字体令牌

| 场景 | 字体 |
|---|---|
| 标题 / 大数字 | 得意黑 SmileySans |
| 数据 / 英文 | JetBrains Mono ExtraBold |
| 正文 | 思源黑体 Light/Regular |
| 引用 / 文艺 | 思源宋体 Light |

字号：大标题 72-96px，数据 100-140px，说明 14-16px。

## 四、质感令牌（治"AI 廉价味"三层）

1. **噪点**：1-3% 透明度，mix-blend overlay
2. **网格**：36px 白线格（4-6% 透明度，边缘淡出遮罩）——深空数据舱专属元素
3. **径向光晕**：顶部 8-10% 强调色光晕

卡片：阴影模糊 ≤40px、透明度 ≤40%；边框半透明白 10-14%。

## 五、动效令牌（克制的三件套）

1. 位移 + 淡入（位移 ≤140px，spring damping 15-17）
2. clip-path 遮罩展开（图表 / 截图）
3. 数字滚动

禁止：旋转、缩放、弹跳、粒子、扫光、运动音效。
节奏：90% 硬切；句间 0.15-0.25s；入场 0.2-0.4s；图表 0.4s 冲到顶。
