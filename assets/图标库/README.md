# leeon 图标库

> 用途：AI 杂谈视频 / PPT / 网页 通用图标素材。按深空数据舱风格（线性、单色、24px 网格）挑选。
> 预览：双击打开同目录 `图标库预览.html`（深色底 + 青色网格，所见即所得）。

## 许可证（都可商用）

- **Lucide**（通用图标）：ISC 许可证（源自 Feather MIT）——免费商用，无需署名。
- **Simple Icons**（品牌图标）：项目整体 CC0——可免费商用；但 logo 属于各品牌商标，公开使用请遵守品牌规范（一般做资讯/评测内容没问题）。
- 全部为 SVG 矢量格式，可直接改色、缩放。

## 用法

1. **改颜色**：图标内部使用 `stroke="currentColor"`，给外层元素设置 `color` 即可一键变色（深空数据舱主色 `#22D3EE` / 文字 `#E8EAED`）。
2. **改大小**：SVG 自带 24x24 viewBox，缩放任意尺寸不糊。
3. **进 Remotion/PPT**：直接 import / 粘贴 SVG 内容，或转成 PNG（透明底）做素材。
4. **更多图标**：本库是精选常用集，需要新图标去 [lucide.dev](https://lucide.dev) 或 [iconify](https://icon-sets.iconify.design) 搜同名 SVG 即可。

## 颜色说明

- **通用图标默认单色**（`#E8EAED` 白灰），不预置配色——做视频/网页时按当期需求给外层 `color` 改色（如主视觉青 `#22D3EE`）。
- **品牌图标保留官方色**（OpenAI 绿、DeepSeek 蓝、Anthropic 陶土、HuggingFace 黄、NVIDIA 荧光绿等）。
