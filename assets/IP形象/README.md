## Q版机器人-bottts 使用说明

- **来源**：[DiceBear bottts](https://www.dicebear.com/styles/bottts)（免费商用，无需署名）
- **生成规则**：`https://api.dicebear.com/9.x/bottts/svg?seed=<任意英文名>`，**种子名相同 → 形象永远相同**，可复现。
- **已有种子**：
  - leeon 系：`leeon-01` ~ `leeon-05`（leeon 主形象候选）
  - AI 系：`ai-bot-01` ~ `ai-bot-03`
  - 场景系：`data-bot`（数据）、`code-bot`（代码）、`lab-bot`（实验）、`neo-bot`（未来感）
- **换形象**：改种子名重新下载即可，无需手动画。
- **改色**：SVG 内 `fill` 为固定色值，替换成品牌色即可（如 `#22D3EE`）。建议整体统一成一个主色。
- **转 PNG**：需要位图时用浏览器/设计软件打开后导出，或装 ImageMagick 批量转换。
