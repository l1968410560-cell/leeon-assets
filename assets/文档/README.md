## 图标库使用约定

- 位置：`素材库/图标库/`，先看 `图标库/图标库预览.html` 挑图标。
- 通用图标：默认单色白灰（`#E8EAED`），SVG 用 `currentColor`，做图/视频时按当期主色改外层 `color`（如 `#22D3EE`）。
- 品牌图标：保留官方品牌色，不要改色。
- 许可证：Lucide（ISC，可商用免署名）、Simple Icons（CC0）；品牌 logo 是各公司商标，遵守品牌规范。
- 细节见 `图标库/README.md`。

## 约定

1. 新收集的通用素材（图标、贴纸、纹理、截图）统一进本目录，按类型建子文件夹。
2. 每个素材文件夹配 README 说明来源、许可证、用法。
3. 做 PPT/视频前：先查素材库 → 没有再到互联网找 → 最后才考虑自绘/生成。

## 推荐开工流程

1. 读 `品牌资产/品牌卡.md`（色板 + 字体 + 质感 + 动效一次拿全）
2. 选 `视频风格模板/` 里的风格（默认深空数据舱）
3. 挑素材：`图标库/` → `插画/科技风-unDraw/` → `IP形象/` → 真实截图
4. 细节见 `素材库扩充清单.md`（还有哪些待补）
