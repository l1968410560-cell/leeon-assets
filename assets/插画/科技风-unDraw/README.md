## 怎么用 / 怎么改色

1. unDraw 原图主色是紫色 `#6c63ff`，附色黄 `#ffd037`、粉 `#fc6681`——**直接贴会偏"老式插画风"**。
2. 改色：用编辑器全局替换 `#6c63ff` → 品牌主色（如 `#22D3EE`）；把 `#ffd037` / `#fc6681` 替换为同一强调色或灰阶，保持全图 ≤3 色。
3. 贴到深色底时：SVG 是浅色背景图，需先抠掉底色（unDraw 多数无背景色块），或置于浅色卡片上使用。
4. 需要批量改色：可用脚本对文件夹内 SVG 做字符串替换（见 `素材库/_scripts/` 可扩展）。
